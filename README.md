# 마음 한 칸 · 나의 작은 정원

기분별 운세와 작은 실천, 30초 호흡, 마음 기록을 담은 브라우저 웹앱입니다.

## 달라진 점
- 밤하늘 위 작은 식물 행성을 모티프로 한 반응형 디자인
- 날마다 바뀌는 작은 실천과 완료/취소 기록
- 4초 들이쉬기와 6초 내쉬기를 3회 안내하는 호흡 타이머
- 기분과 120자 한 줄을 저장하는 지난 7일 마음 정원
- 날짜별 기록 다시 읽기, 오늘 기록 수정, 개별 삭제
- 연속 방문 일수 표시
- 기존 운세, 응원 보관함, PNG 이미지 저장, 공유 유지

## 실행
`index.html`을 브라우저에서 열거나, 이 폴더에서 다음 명령을 실행하세요.

```sh
python -m http.server 8765 --bind 127.0.0.1
```

그다음 http://127.0.0.1:8765/ 에 접속하세요. 별도 패키지 설치나 API 키는 필요 없습니다.

기록은 접속한 브라우저의 localStorage에만 저장됩니다. 다른 기기나 브라우저로 동기화되지 않으며, 브라우저 데이터를 지우면 기록도 사라집니다. 운세는 날짜와 기분별로 정해지는 가벼운 응원 콘텐츠입니다.

## GitHub에 올리기
새 저장소를 만든 뒤 `index.html`, `style.css`, `app.js`, `README.md`를 저장소 최상위에 업로드하세요. GitHub Pages를 사용한다면 해당 브랜치의 최상위 폴더를 배포 대상으로 선택하면 됩니다.

## 확인한 내용
Microsoft Edge에서 기존 기능 14개, 새 기능 11개를 자동 테스트했습니다. 이미지 생성, 클립보드 복사, 저장 실패 복구, 기록 수정/삭제, 호흡 타이머, 320~1440px 화면 크기를 확인했습니다. OS 네이티브 공유 창은 기기에 따라 달라 직접 검증하지 않았습니다.
